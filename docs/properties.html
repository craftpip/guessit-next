Properties

Every value the engine can return, what it means, and a name that produces it. Field shapes are defined in the API reference — this page explains the vocabulary.

Release kinds

Returned as kind by categorize. Each name lands in exactly one kind.

  • collection — several seasons at once. Show Name S01-S03 1080p → seasons 1–3, seasonList: [1, 2, 3].
  • season_batch — one whole season. Show Name (2018) Season 1 - 720p → season 1 (the - 720p is a resolution, not a range).
  • episode — a single episode. Show Name S01E01 1080p → season 1, episode 1.
  • episode_collection — several episodes of one season. Show Name S01E01-E13 1080p → season 1, episodes 1–13.
  • movie — a film, recognized by year without season/episode markers. Movie Title (2020) 1080p → year 2020.
  • others — nothing recognizable (featurettes, packs of extras, unparsable names). Carries no season/episode numbers.

File types

Returned as type by classifyFile.

  • series — belongs to a show. Show - S01E02.mkv → season 1, episode 2, confidence 0.9.
  • movie — belongs to a film. Movie Title (2020).mkv → year 2020, confidence 0.75.
  • extra — supporting material, never the main content: sample | trailer | behind | deleted | interview | featurette | short | special | extra (in extra_type). Show - Trailer.mkv → extra/trailer.
There is no skip type. Low-confidence files, incomplete downloads, and non-media are your application's call — the classifier only ever says what a name looks like.

Ranges, always preserved where it matters

  • episodeEnd — last episode of a range (S01E01-E13 → episode 1, episodeEnd 13).
  • seasonRange / seasonList — seasons spanned by a multi-season item (S01-S03 → [1, 3] / [1, 2, 3]).
  • seasonEnd — only when one range crosses seasons.
  • isCompletePack — true for “Complete Series” / “All Seasons” / “… COMPLETE”.
  • For file routing, classifyFile collapses a range to its start episode (a 13-episode file still sorts under episode 1) while keeping the end in episodeEnd.
