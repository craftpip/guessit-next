guessit-next Overview Documentation

Documentation

Code documentation for developers building with guessit-next — not an end-user guide. If you just want to know what the project does, start at Overview.

Contents

  • API reference — the four functions (categorize, extractSE, classifyFile, classifyFiles), what each one answers, and every field it returns.
  • Properties — what each returned value means, with a producing name: release kinds, file types, extra types, ranges.
  • CLI & daemon — the bin/index.js binary: one-shot checks, --batch mode, and the --serve stdio daemon for Python apps.
  • Parsing guards — the parsing rules catalog: number caps, codec traps, anime conventions, “complete” handling, folder authority. Each rule is locked in by a test.
  • Known limitations — name shapes a name-only parser cannot resolve, with workarounds.
Returned field names are the public contract your app programs against. They are locked by tests/cli.test.js — any change to these bytes is a breaking change.
