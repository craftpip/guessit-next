CLI & daemon

One binary (bin/index.js) for spot-checks, batch jobs, and the Python consumer's stdio daemon.

One-shot modes

# One torrent name → categorize JSON
node bin/index.js --json "Show Name S01E01.mkv"
# → {"kind":"episode","season":1,"episode":1,"episodeEnd":null,…}

# One library file → classifyFile JSON (parent folders participate)
node bin/index.js --json-file "/data/torrents/Neutral Show/10-Conclusion.mkv" --root /data/torrents
# → {"type":"series","title":"Neutral Show","episode":10,…}

--batch: JSON-lines in, JSON-lines out

Stdin: one { op, … } object per line. Stdout: one result object per line, same order.

echo '{"op":"categorize","name":"Show Name S01-S03 1080p"}' | node bin/index.js --batch
# → {"kind":"collection","seasonRange":[1,3],"seasonList":[1,2,3],…}

Ops

OpInput fieldsRuns
categorizenamecategorize(name)
classifyFilecandidate, seriesAliases?classifyFile(candidate, { seriesAliases })
classifyFilescandidates, seriesAliases?classifyFiles(candidates, { seriesAliases })

--serve: stdio daemon

node bin/index.js --serve --json

Same ops as --batch, looped until stdin EOF. The Python consumer spawns one daemon per scan and speaks JSON-lines over the pipe — no per-file process startup cost. --json is accepted for symmetry; output is always JSON.
