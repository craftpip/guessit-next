CLI & daemon

One binary (bin/index.js) with three modes: check a single name, process a batch, or run a long-lived daemon your Python app talks to.

Check one name

# One release name → categorize JSON
node bin/index.js --json "Show Name S01E01.mkv"
# → {"kind":"episode","season":1,"episode":1,"episodeEnd":null,…}

# One library file → classifyFile JSON (parent folders participate in parsing)
node bin/index.js --json-file "/data/torrents/Neutral Show/10-Conclusion.mkv" --root /data/torrents
# → {"type":"series","title":"Neutral Show","episode":10,…}

Use this for spot-checks while developing, or when your app only has the occasional name to classify.

--batch: many names, one process

Send one { op, … } object per line on stdin; get one result object per line on stdout, in the same order.

echo '{"op":"categorize","name":"Show Name S01-S03 1080p"}' | node bin/index.js --batch
# → {"kind":"collection","seasonRange":[1,3],"seasonList":[1,2,3],…}

Ops

OpInput fieldsRuns
categorizenamecategorize(name)
classifyFilecandidate, seriesAliases?classifyFile(candidate, { seriesAliases })

Field meanings are in the API reference.

--serve: the Python daemon

node bin/index.js --serve --json

Same ops as --batch, looped until stdin closes. Your Python app spawns one daemon and pipes a whole scan through it — no per-file process startup cost. (--json is accepted for symmetry; output is always JSON.) See the Python example on the Overview page.
