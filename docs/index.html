guessit-next

A media-name classification engine with wrappers for Node.js and Python. Give it a media file or folder name — it tells you the title, the season and episode numbers, and what kind of release it is. Zero dependencies.

categorize('Show Name S01E01-E13 1080p');
// → { kind: 'episode_collection', season: 1, episode: 1, episodeEnd: 13,
//     seasonEnd: null, seasonRange: null, seasonList: null,
//     isCompletePack: false }

Install

Requires Node.js ≥ 20.

git clone https://github.com/craftpip/guessit-next.git guessit-next
cd guessit-next
npm install   # installs nothing extra — no runtime dependencies

Usage

From Node.js — import it in-process:

import { categorize, classifyFile, classifyFiles, extractSE } from 'guessit-next';

categorize('Show Name S01E01-E13 1080p');
// → { kind: 'episode_collection', season: 1, episode: 1, episodeEnd: 13, … }

classifyFile({ name: 'Show - S01E02.mkv', source_path: '/data/downloads/Show - S01E02.mkv',
  source_root: '/data/downloads', container_path: null, relative_path: null,
  file_size: null });
// → { type: 'series', season: 1, episode: 2, confidence: 0.9, … }

From Python — talk to the stdio daemon over JSON-lines (one process handles a whole batch, no per-file startup cost):

import json, subprocess

daemon = subprocess.Popen(['node', 'bin/index.js', '--serve', '--json'],
                          stdin=subprocess.PIPE, stdout=subprocess.PIPE, text=True)
daemon.stdin.write(json.dumps({"op": "categorize", "name": "Show Name S01-S03 1080p"}) + "\n")
daemon.stdin.flush()
print(json.loads(daemon.stdout.readline()))
# → {"kind": "collection", "seasonRange": [1, 3], "seasonList": [1, 2, 3], …}

From the shell — spot-check a name or pipe a batch:

node bin/index.js --json "Show Name S01E01.mkv"
echo '{"op":"categorize","name":"Show Name S01-S03 1080p"}' | node bin/index.js --batch

What it is for

  • Download apps — decide what a release name represents before fetching it: a full collection, a season batch, episodes, a movie, or something unrecognized.
  • Media libraries — sort files into shows and movies using the file name and its folder names together, with season/episode numbers and a confidence score per file.
  • Whole folders — check a full folder at once and get a per-folder summary, with a flag when one file disagrees with the rest.

Two vocabularies, one core. Release kinds (collection | season_batch | episode | episode_collection | movie | others) and file types (series | movie | extra) are different views of the same parse core. Your app decides what to skip — the classifier never emits skip.

Support

Found a name that parses wrong? Open an issue at github.com/craftpip/guessit-next with the obfuscated name (same tokens, fake title — never paste real release groups). Cases the parser deliberately does not resolve are listed under Known limitations.
