guessit-next

One implementation of “extract seasons, episodes, title and type from media file names and folder names” — written once, tested once, consumed twice (a Node.js torrent orchestrator in-process, a Python media organizer over stdio).

What it answers

  • Show Name S01E01-E13 1080p → an episode collection: season 1, episodes 1–13.
  • Show Name (2018) Season 1 - 720p → a season batch: season 1 (the - 720p is a resolution, not a range end).
  • 10-Conclusion.mkv inside Neutral Show/ → series: title Neutral Show, episode 10, episode title Conclusion.
  • A torrent folder of 12 episodes + an OP → one group: title agreed, seasons [1], episodes {1: [1…12]}.

Install & use

Requires Node.js ≥ 20. Zero runtime dependencies, pure ESM.

git clone <repo-url> guessit-next
cd guessit-next
npm install   # installs nothing extra — no runtime dependencies
import { categorize, classifyFile, classifyFiles, extractSE } from 'guessit-next';

categorize('Show Name S01E01-E13 1080p');
// → { kind: 'episode_collection', season: 1, episode: 1, episodeEnd: 13, … }

classifyFile({ name: 'Show - S01E02.mkv', source_path: '/data/downloads/Show - S01E02.mkv',
  source_root: '/data/downloads', container_path: null, relative_path: null,
  file_size: null, in_progress: false });
// → { type: 'series', season: 1, episode: 2, confidence: 0.9, … }

Four functions

FunctionQuestion it answers
categorize(name)What does one torrent/release name represent? (download decisions)
extractSE(name)What season/episode structure does this name carry? (ranges preserved)
classifyFile(candidate)Where does one file belong in a library?
classifyFiles(candidates)What does this whole folder contain, and do its files agree?

Details: API reference. Shell/daemon usage: CLI & daemon. Parsing rules: guards catalog.

Two vocabularies, one core. Torrent kinds (collection | season_batch | episode | episode_collection | movie | others) and file types (series | movie | extra | skip) are different views of the same parse core. skip is scanner-side — the classifier never emits it.
