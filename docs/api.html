API reference

Import from 'guessit-next' (or ./src/index.js in a checkout). Field names are the contract — locked by tests/cli.test.js.

categorize(name) → CategoryResult

Classify one torrent/release/file name into exactly one kind. Kind priority: collection > season_batch > episode_collection > episode > movie > others.

FieldMeaning
kindcollection | season_batch | episode | episode_collection | movie | others
seasonthe single season the item belongs to (or null)
episodethe (start) episode number (or null)
episodeEndlast episode of a range/collection (or null)
seasonEndseason of episodeEnd when a range crosses seasons (or null)
seasonRange[min, max] seasons spanned by a multi-season item (or null)
seasonListexplicit sorted list of every season contained (or null)
isCompletePacktrue for “Complete Series” / “All Seasons” / “… COMPLETE”

extractSE(name) → SE

Same parse core as categorize, without the kind decision. Ranges preserved.

FieldMeaning
season / episodestart of the structure (or null)
episodeEnd / seasonEndrange end; seasonEnd only for cross-season ranges
seasonRange / seasonListfor season spans with no episodes involved

classifyFile(candidate, opts?) → ClassificationResult

Candidate

FieldMeaning
namefile name, e.g. Show - S01E02.mkv
source_pathfull path of the file
source_rootscan root the file was found under
source_root_keyopaque key of the scan root
container_pathcontaining folder (torrent root), if any
relative_pathpath of the file relative to the container, if any (carries Season 02/… subfolders)
file_sizesize in bytes, if known (sample-size heuristic needs it)
in_progressreserved; the classifier ignores it (scanners use it for skip)

opts = { seriesAliases?: Record<string,string> } maps a detected title to its canonical name.

Result

FieldMeaning
typeseries | movie | extra (never skip)
titleshow/movie title
episode_titleepisode title, when derivable (or null)
series_aliasalternative title, e.g. foreign arc name (or null)
yearrelease year (or null)
season / episodenumbers; ranges collapse to the start episode
episodeEndrange end for multi-episode files (or null)
confidence0–1 confidence
reasonshort human-readable reason
extra_typefor extra: sample | trailer | behind | deleted | interview | featurette | short | special | extra

Confidence ladder

EvidenceTypeConfidenceReason
explicit episodeseries0.9Matched episode/season pattern
season onlyseries0.8Matched season pattern
year, no S/Emovie0.75Matched year without season/episode
standalone filemovie0.65Defaulted standalone file to movie
extra markerextra≥ 0.85Detected <type> extra/special marker
A small movie-size file with no sample marker stays movie with a “sample-size suspect” reason suffix — the scanner flags it, the file stays editable. Only a real sample marker routes to extra/sample.

classifyFiles(candidates, opts?) → { results, groups }

results: one ClassificationResult per input, in input order. groups: one summary per folder — group key is container_path, or source_path for loose files (each its own group, so unrelated shows never force agreement).

FieldMeaning
keyfolder path (or lone file path)
title / typemajority identity across the group's series/movie results
seasonssorted unique seasons contained
episodesBySeason{ "<season>": [sorted unique episodes] }
fileCount / episodeFileCount / extraFileCountcounts
consistentfalse when a file disagrees with the folder majority
conflictshuman-readable descriptions of each disagreement

A disagreeing file gets lowered confidence with a conflict reason; extras never break agreement. Empty input returns { results: [], groups: [] }.
